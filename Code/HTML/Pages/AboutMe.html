Notable Projects

INCISIV: CleanSheet

CleanSheet is a VR goalkeeper simulator developed in Unity. It began as a professional training tool for football clubs under the name CleanSheet Pro for the HTC Vive. During this phase, I developed the timeline‑based set system used to orchestrate passing sequences and shooting drills.

The project later evolved into CleanSheet VR for the Meta Quest 2. I expanded the system with multiplayer game modes, in‑app purchasing, and further improvements to the set system.

These new features were released in time for the Meta Quest 3 launch, with CleanSheet appearing on the Quest Store on launch day.

Grimoire Mathematica: The Deep Dark

The Deep Dark began as a 2024 game jam project exploring shadows as a cell-based fluid simulation, focusing on the interactions between the player and placed light sources. It later expanded into a larger project featuring procedural world generation and fully GPU‑driven simulations.

The project also served as a platform for developing Unity editor tools for efficient geometry instancing and advanced material‑driven animation workflows. It is currently in active development for both Windows and Linux.
